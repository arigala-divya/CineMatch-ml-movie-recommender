# CineMatch — ML-Powered Movie Recommender

An end-to-end Applied Machine Learning project that segments customers into meaningful groups using unsupervised learning, then delivers personalised movie recommendations through a hybrid scoring engine and a live web application.

---

## Problem Statement

Generic recommendation systems treat all users the same — leading to poor engagement and irrelevant suggestions. CineMatch solves this by automatically grouping users into distinct segments based on age and viewing behaviour, then tailoring top-10 movie recommendations to each segment using a hybrid scoring model.

## Pipeline Overview

### Step 1 — Customer Segmentation (`ml/step1_segmentation.py`)
- Loads `data/raw/customers.csv`
- Encodes genre and normalises features with `StandardScaler`
- Tests K = 2–10 using the **Elbow Method** and **Silhouette Score**
- Runs **K-Means** with K = 4; maps clusters to age groups by average age
- Outputs `data/processed/customer_segments.csv` + 3 visualisation plots

### Step 2 — Segment Insights (`ml/step2_insights.py`)
- Loads `data/processed/customer_segments.csv`
- Computes per-segment stats: avg age, avg rating, activity, top genre
- Generates a 4-panel insights dashboard and a rating/engagement deep-dive
- Outputs `data/processed/segment_insights.csv` + 2 visualisation plots

### Step 3 — Recommendation Engine (`ml/step3_recommendations.py`)
- Merges movies + ratings + customer segments
- Computes a **hybrid score** per movie per age group:

  ```
  hybrid_score = 0.5 × weighted_rating
               + 0.3 × popularity_score
               + 0.2 × consistency_score
  ```

- Outputs recommendations for each age group, each cluster, and globally

### Web Application
- **Backend** (`backend/app.py`): Flask API at `/api/result` — classifies a user's age into a segment and returns the top 10 movies by hybrid score
- **Frontend** (`frontend/`): React + Vite form — user enters name & age, receives their segment and personalised recommendations

## Quick Start

### Prerequisites
- Python 3.9+
- Node.js 18+

### 1 — Install Python dependencies
```bash
pip install -r requirements.txt
```

### 2 — Run the ML pipeline (only needed once to generate processed data)
```bash
python ml/run_pipeline.py
```

### 3 — Start the Flask backend
```bash
python backend/app.py
# Runs on http://localhost:5000
```

### 4 — Start the React frontend
```bash
cd frontend
npm install
npm run dev
# Runs on http://localhost:5173
```

Open `http://localhost:5173`, enter a name and age, and get your recommendations.

## Key Results

- Young Adults (18–35) form the largest segment (~40% of users)
- Animation & Drama score highest in average ratings across segments
- Hybrid scoring outperforms pure average-rating ranking by balancing popularity and consistency
- Elbow Method converged clearly at K = 4, validating the age-group hypothesis
